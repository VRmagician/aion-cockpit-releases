# 🚗 AION Cockpit

ศูนย์รวมการติดตั้งและดาวน์โหลด **AION Cockpit** สำหรับรถยนต์ไฟฟ้า AION (รองรับ AION Y Plus, AION V, AION ES, Hyptec HT)

---

## 📱 สำหรับผู้ใช้งาน Android (แอปพลิเคชัน APK)
สำหรับผู้ใช้สมาร์ทโฟน Android สามารถดาวน์โหลดไฟล์ติดตั้ง `.apk` เวอร์ชันล่าสุดได้โดยตรงที่หน้า Releases:
👉 **[ดาวน์โหลด AION Cockpit APK เวอร์ชันล่าสุด](https://github.com/VRmagician/aion-cockpit-releases/releases)**

---

## 🍏 สำหรับผู้ใช้งาน iPhone / iOS / iPad (PWA Web Dashboard)
สำหรับผู้ใช้ iPhone และอุปกรณ์ iOS สามารถเปิดใช้งานเซิร์ฟเวอร์ส่วนตัวฟรีตลอด 24 ชั่วโมง ผ่านระบบ Cloud (Render.com) ได้ด้วยคลิกเดียว:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/VRmagician/aion-cockpit-releases)

### 📋 ขั้นตอนการติดตั้งใช้งานบน iPhone:
1. **กดปุ่ม `Deploy to Render` ด้านบน**
   * หากยังไม่มีบัญชี Render สามารถกด Sign up ฟรีด้วย Google หรือ GitHub ได้ทันที
2. **กดปุ่ม "Apply" หรือ "Create Web Service"**
   * ระบบ Render จะทำการสร้างเซิร์ฟเวอร์ส่วนตัวของคุณที่ประเทศสิงคโปร์ (ใช้เวลาประมาณ 1-2 นาที)
3. **เปิดใช้งานบน iPhone:**
   * เมื่อระบบสร้างเสร็จ คุณจะได้รับ URL เว็บส่วนตัว (เช่น `https://aion-cockpit-xxxx.onrender.com`)
   * นำลิงก์ไปเปิดในเบราว์เซอร์ **Safari** บน iPhone
   * กดปุ่มแชร์ (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้นที่แถบด้านล่างของ Safari)
   * เลือกเมนู **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"**
4. **เปิดใช้งานแอป:**
   * ไอคอน AION Cockpit จะปรากฏบนหน้าจอโฮมของ iPhone สามารถกดเปิดใช้งานได้เต็มจอเสมือนแอปแท้ทันที!

* **ไม่มีค่าใช้จ่าย:** สามารถใช้งานบนโควต้า Free Tier ของ Render ได้ฟรีตลอดการใช้งาน
